This guide extends the [Quick start](/docs/getting-started/quick-start) into the shape of a real service. It assumes the application is [registered](/docs/getting-started/register-the-application) with **LiteLLM support** on, a back-channel logout URI, and the machine scopes. It needs the `axum` cargo feature of the SDK.

## Configuration values

| Variable | Example | Purpose |
| --- | --- | --- |
| `PUBLIC_URL` | `https://app.example.com` | Public origin of your application. No trailing slash. |
| `AUTH_ISSUER` | `https://auth.example.com` | auth-service URL. |
| `AUTH_CLIENT_ID` | `my-app` | The application's client id. |
| `AUTH_CLIENT_SECRET` | `<client-secret>` | Never commit it. |
| `AUTH_COOKIE_SECRET` | `<32+ random characters>` | Seals the sign-in cookie. |
| `GATEWAY_URL` | `https://llm.example.com` | The LiteLLM gateway, when used. |

These names are yours: the SDK reads no environment variable.

## The server

```rust [src/main.rs]
use std::sync::Arc;

use auth_ai::axum::{AuthError, AuthSession, auth_router};
use auth_ai::web::{
    AuthHandlers, MemorySessionStore, Session, SessionStore, SessionsEndedCallback, is_cross_site,
};
use auth_ai::{
    AiClient, AuthAiError, AuthClient, AuthClientConfig, ErrorCallback, ErrorCode, GatewayModel,
    GrantManager, MemoryGrantStore, WebRequest,
};
use axum::extract::{FromRef, Request, State};
use axum::middleware::{self, Next};
use axum::response::{IntoResponse, Response};
use axum::routing::get;
use axum::{Json, Router};

#[derive(Clone)]
struct AppState {
    handlers: AuthHandlers,
    ai: AiClient,
}

impl FromRef<AppState> for AuthHandlers {
    fn from_ref(state: &AppState) -> Self {
        state.handlers.clone()
    }
}

fn env(name: &str) -> Result<String, Box<dyn std::error::Error>> {
    std::env::var(name)
        .ok()
        .filter(|value| !value.is_empty())
        .ok_or_else(|| format!("Missing environment variable {name}").into())
}

// State-changing API calls must come from this site.
async fn same_origin_api(
    State(handlers): State<AuthHandlers>,
    request: Request,
    next: Next,
) -> Response {
    let mutating = !matches!(request.method().as_str(), "GET" | "HEAD" | "OPTIONS");
    if mutating && request.uri().path().starts_with("/api/") {
        let mut web = WebRequest::new(request.method().as_str(), handlers.origin());
        for name in ["origin", "sec-fetch-site"] {
            if let Some(value) = request.headers().get(name).and_then(|v| v.to_str().ok()) {
                web = web.with_header(name, value);
            }
        }
        if is_cross_site(&web, handlers.origin()) {
            return AuthError(ErrorCode::Ses004.error()).into_response();
        }
    }
    next.run(request).await
}

async fn list_models(
    State(state): State<AppState>,
    AuthSession(session): AuthSession,
) -> Result<Json<Vec<GatewayModel>>, AuthError> {
    let user = state.ai.for_user(&session.user_id)?;
    Ok(Json(user.gateway()?.list_models().await?))
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    tracing_subscriber::fmt::init();
    let public_url = env("PUBLIC_URL")?;

    let config = AuthClientConfig::builder(
        env("AUTH_ISSUER")?,
        env("AUTH_CLIENT_ID")?,
        format!("{public_url}/auth/callback"),
    )
    .client_secret(env("AUTH_CLIENT_SECRET")?)
    .post_logout_redirect_uri(format!("{public_url}/auth/logout/callback"))
    .gateway_url(env("GATEWAY_URL")?)
    .build()?;
    let auth = AuthClient::new(config)?;

    // In memory: fine for a demo or one instance. Use database stores in production.
    let grants = GrantManager::new(auth.clone(), MemoryGrantStore::new());
    let ai = AiClient::new(auth.clone(), grants.clone());
    let sessions: Arc<dyn SessionStore> = Arc::new(MemorySessionStore::new());

    // Details belong in logs, never in responses.
    let on_error: ErrorCallback = Arc::new(|err: &AuthAiError| {
        tracing::warn!(error = %err.to_json(), "auth handler error");
    });
    let on_sessions_ended: SessionsEndedCallback = Arc::new(|ended: Vec<Session>| {
        Box::pin(async move {
            tracing::info!(count = ended.len(), "sessions ended");
            Ok(())
        })
    });

    let handlers = AuthHandlers::builder(auth, grants, sessions, env("AUTH_COOKIE_SECRET")?)
        .ai(ai.clone()) // adds /auth/wallet, /auth/wallet/stats and /auth/models for the frontend
        .on_error(on_error)
        .on_sessions_ended(on_sessions_ended)
        .build()?;

    let app = Router::new()
        .merge(auth_router::<AppState>(handlers.clone()))
        .route("/api/models", get(list_models))
        .layer(middleware::from_fn_with_state(
            handlers.clone(),
            same_origin_api,
        ))
        .with_state(AppState { handlers, ai });
    axum::serve(tokio::net::TcpListener::bind("0.0.0.0:3000").await?, app).await?;
    Ok(())
}
```

## What each piece does

- **`auth_router`** adds one catch-all route below `handlers.base_path()` (`/auth` by default). Mount it at the root of the application: the path the handlers see must include the base path. Any `AuthAiError` they hit is answered with the public error envelope.
- **`FromRef<AppState> for AuthHandlers`** lets the extractors and the router find the handlers in your own state. With `AuthHandlers` itself as the state, nothing is needed.
- **`on_error`** receives the cause of every failed callback, every unexpected failure, and a failed grant revocation. The browser only ever sees the generic code. See [Security model](/docs/concepts/security-model).
- **`on_sessions_ended`** fires after a sign-out or a back-channel logout: close WebSockets, drop per-user caches. It returns a boxed future, and an `Err` fails the request that ended the sessions.
- **The middleware** applies the cross-site check the SDK enforces only on `/auth/logout` to your own state-changing routes. `is_cross_site` compares `Origin` (or `Sec-Fetch-Site`) with `handlers.origin()`, the origin of your registered `redirect_uri`.
- **Proxies.** The SDK never reads the `Host` or `X-Forwarded-*` headers to build URLs: it builds them on the origin of `redirect_uri`. Your proxy settings only matter for your own logging and client IPs.
- **Shutdown.** `AuthClient` and its clones share one HTTP client: there is nothing to close.

## Protecting routes

| Extractor | Effect |
| --- | --- |
| `AuthSession(session)` | Answers `401` `SES_001` when signed out; hands you the `Session` otherwise. |
| `OptionalAuthSession(session)` | Hands you an `Option<Session>`: `None` when signed out. |

Both read the cookie and renew the claims when due. They never read the request body, so a route can still take a `Json` or a `Form`. If the session store or the renewal fails, the request is answered with that error (`SRV_001`, `TOK_001`, `OIDC_*`).

Check entitlements on the server, in the route that does the work:

```rust
use auth_ai::axum::AuthSession;
use auth_ai::web::AuthHandlers;
use auth_ai::{PermissionAction, has_permission};
use axum::routing::post;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use axum::{Json, Router};
use serde_json::json;

async fn create_report(AuthSession(session): AuthSession) -> Response {
    if !has_permission(&session.claims, "reports", PermissionAction::Write) {
        return (
            StatusCode::FORBIDDEN,
            Json(json!({ "error": { "code": "FORBIDDEN" } })),
        )
            .into_response();
    }
    Json(json!({ "created": true })).into_response()
}

fn report_routes() -> Router<AuthHandlers> {
    Router::new().route("/api/reports", post(create_report))
}
```

`FORBIDDEN` is an example of your own application's error code: the SDK registry has no authorisation code of that kind.

When a route of yours returns `Err(AuthError(err))` (for example `GW_001` from the gateway), the response carries the public envelope and the status that `auth_ai::web::status_for` gives its code: `402` for `GW_001`, `429` for `GW_002`, `401` for `SES_001`. `AuthError` implements `From<AuthAiError>`, so `?` converts for you in a handler that returns `Result<_, AuthError>`. See the [error codes](/docs/reference/error-codes).

## Serving the frontend

`auth_router` only answers below `base_path`. Serve your static frontend however you like (for example with `tower_http::services::ServeDir` as a fallback service); the browser calls `/auth/me` to learn who is signed in. See [Use the TypeScript client](/docs/guides/frontend/use-the-typescript-client).

## Keep the authorization code out of the logs

The callback URL carries the authorization code in its query string, and `tower_http::trace::TraceLayer` records the full URI in its default span. Record the path only:

```rust
use axum::Router;
use axum::body::Body;
use axum::http::Request;
use tower_http::trace::TraceLayer;

fn without_query_strings<S>(app: Router<S>) -> Router<S>
where
    S: Clone + Send + Sync + 'static,
{
    app.layer(TraceLayer::new_for_http().make_span_with(|request: &Request<Body>| {
        tracing::info_span!("request", method = %request.method(), path = request.uri().path())
    }))
}
```

Apply the same rule to any other access log, reverse proxy included.
