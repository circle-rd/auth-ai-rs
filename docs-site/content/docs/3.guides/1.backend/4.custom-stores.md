The in-memory stores (`MemorySessionStore`, `MemoryGrantStore`, `InProcessGrantLock`, `MemoryReplayStore`) are for demos, tests and a **single instance**: a restart signs everyone out, and replicas cannot share them. In production, implement the traits on your application's database.

The four contracts are `async_trait` traits: add the `async-trait` crate to your own dependencies, implement them on your own types, and hand them to the SDK. A store that fails reports `SRV_001` (build it with `ErrorCode::Srv001.error()`).

| Trait | Holds | Shared across replicas? |
| --- | --- | --- |
| `SessionStore` | Browser sessions: claims and ID token. | Yes, required. |
| `GrantStore` | One refresh token per user. | Yes, required. |
| `GrantLock` | Mutual exclusion of refreshes per grant. | Yes, with several replicas. |
| `ReplayStore` | The `jti` of accepted logout tokens. | Yes, with several replicas. |

## `SessionStore`

From `auth_ai::web`. Records are keyed by `Session::id`, which is already the SHA-256 of the cookie value: store it as is. Index `user_id` and `session_id`. The handlers take the store as an `Arc<dyn SessionStore>`.

| Method | Contract |
| --- | --- |
| `create(&session)` | Inserts the session. |
| `get(session_key)` | Returns the session, or `None` for an unknown **or expired** one (`expires_at`, in Unix seconds, is in the past). |
| `update(&session)` | Replaces an existing session (the claims renewal). Do nothing if it no longer exists, so a renewal never resurrects a session that was ended meanwhile. |
| `delete(session_key)` | Removes the session. Idempotent. |
| `delete_by_provider_session(session_id)` | Removes **every** session whose `session_id` equals the argument and returns what was removed. Back-channel logout relies on the returned `Vec<Session>` to revoke grants. |
| `count_by_user(user_id)` | Number (`usize`) of **non-expired** sessions of the user. The grant is revoked when it reaches zero after a sign-out. |

`Session` has `id`, `user_id`, `session_id` (the provider session, an `Option<String>`), `claims` (an `IdTokenClaims`), `id_token` (a `SecretString`), `created_at`, `expires_at` and `renew_at` (all `i64` Unix seconds). It holds `claims` and `id_token`: treat them as sensitive. Purge expired rows periodically.

## `GrantStore`

From `auth_ai`. The provider rotates the refresh token on every use, so a store holds **exactly one value per grant**.

| Method | Contract |
| --- | --- |
| `get(grant_id)` | The refresh token as `Option<SecretString>`, or `None`. |
| `set(grant_id, &refresh_token)` | Inserts or **overwrites**. |
| `delete(grant_id)` | Removes the grant. Idempotent. |

The refresh token is a long-lived credential: **encrypt it at rest** (for example AES-256-GCM with a key from your secret manager).

## `GrantLock`

`hold(grant_id)` returns a `LockGuard`. It must let one holder at a time through for a given grant, and release the lock when the guard is dropped, including on an early return or a panic. Build the guard with `LockGuard::new(value)`, where `value` is whatever releases the lock when it is dropped (a database transaction, a guard of your lock client). Holders of different grants may run in parallel. The default, `InProcessGrantLock`, only covers one process. Pass yours with `GrantManager::builder(auth, store).lock(lock).build()`.

## `ReplayStore`

From `auth_ai::server`. `claim(jti, expires_at)` must be **atomic**: `true` the first time a `jti` is seen, `false` afterwards, until `expires_at` (Unix seconds, an `f64`). Pass your store to `AuthHandlers::builder(...).replay_store(Arc::new(store))`.

## PostgreSQL and Redis sketch

::callout{icon="i-lucide-triangle-alert" color="warning"}
This is an **example to adapt**, not an SDK feature. It was run against PostgreSQL 17 and Redis 7 with `sqlx` 0.8 and `redis` 0.32: sessions (create, get, expiry, update, deletion by provider session, count), grants (round trip, encryption at rest, binding to the grant id), mutual exclusion and release of the lock, and the replay store. Check everything against your own database, schema conventions and secret management.

The session store. The next blocks are one file, `src/auth_stores.rs`:

```rust [src/auth_stores.rs]
use std::time::{SystemTime, UNIX_EPOCH};

use async_trait::async_trait;
use auth_ai::server::ReplayStore;
use auth_ai::web::{Session, SessionStore};
use auth_ai::{
    AuthAiError, ErrorCode, GrantLock, GrantStore, IdTokenClaims, LockGuard, Result, SecretString,
};
use aws_lc_rs::aead::{AES_256_GCM, Aad, NONCE_LEN, Nonce, RandomizedNonceKey};
use redis::aio::ConnectionManager;
use sqlx::PgPool;
use sqlx::types::Json;

fn store_error(err: impl std::error::Error + Send + Sync + 'static) -> AuthAiError {
    ErrorCode::Srv001
        .error()
        .with_message("The auth store failed")
        .with_source(err)
}

#[derive(sqlx::FromRow)]
struct SessionRow {
    id: String,
    user_id: String,
    provider_session_id: Option<String>,
    claims: Json<IdTokenClaims>,
    id_token: String,
    created_at: i64,
    expires_at: i64,
    renew_at: i64,
}

impl From<SessionRow> for Session {
    fn from(row: SessionRow) -> Self {
        Self {
            id: row.id,
            user_id: row.user_id,
            session_id: row.provider_session_id,
            claims: row.claims.0,
            id_token: SecretString::new(row.id_token),
            created_at: row.created_at,
            expires_at: row.expires_at,
            renew_at: row.renew_at,
        }
    }
}

pub struct DbSessionStore {
    pool: PgPool,
}

impl DbSessionStore {
    pub const fn new(pool: PgPool) -> Self {
        Self { pool }
    }
}

#[async_trait]
impl SessionStore for DbSessionStore {
    async fn create(&self, session: &Session) -> Result<()> {
        sqlx::query(
            "INSERT INTO auth_sessions \
             (id, user_id, provider_session_id, claims, id_token, created_at, expires_at, renew_at) \
             VALUES ($1, $2, $3, $4, $5, $6, $7, $8)",
        )
        .bind(&session.id)
        .bind(&session.user_id)
        .bind(&session.session_id)
        .bind(Json(&session.claims))
        .bind(session.id_token.expose_secret())
        .bind(session.created_at)
        .bind(session.expires_at)
        .bind(session.renew_at)
        .execute(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(())
    }

    async fn get(&self, session_key: &str) -> Result<Option<Session>> {
        let row = sqlx::query_as::<_, SessionRow>(
            "SELECT * FROM auth_sessions \
             WHERE id = $1 AND expires_at > extract(epoch FROM now())::bigint",
        )
        .bind(session_key)
        .fetch_optional(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(row.map(Session::from))
    }

    async fn update(&self, session: &Session) -> Result<()> {
        // Updates an existing row only: never resurrects an ended session.
        sqlx::query(
            "UPDATE auth_sessions \
             SET claims = $2, id_token = $3, expires_at = $4, renew_at = $5 WHERE id = $1",
        )
        .bind(&session.id)
        .bind(Json(&session.claims))
        .bind(session.id_token.expose_secret())
        .bind(session.expires_at)
        .bind(session.renew_at)
        .execute(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(())
    }

    async fn delete(&self, session_key: &str) -> Result<()> {
        sqlx::query("DELETE FROM auth_sessions WHERE id = $1")
            .bind(session_key)
            .execute(&self.pool)
            .await
            .map_err(store_error)?;
        Ok(())
    }

    async fn delete_by_provider_session(&self, session_id: &str) -> Result<Vec<Session>> {
        let rows = sqlx::query_as::<_, SessionRow>(
            "DELETE FROM auth_sessions WHERE provider_session_id = $1 RETURNING *",
        )
        .bind(session_id)
        .fetch_all(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(rows.into_iter().map(Session::from).collect())
    }

    async fn count_by_user(&self, user_id: &str) -> Result<usize> {
        let count: i64 = sqlx::query_scalar(
            "SELECT count(*) FROM auth_sessions \
             WHERE user_id = $1 AND expires_at > extract(epoch FROM now())::bigint",
        )
        .bind(user_id)
        .fetch_one(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(usize::try_from(count).unwrap_or(0))
    }
}
```

The grant store encrypts the refresh token with AES-256-GCM, with a random nonce stored in front of the ciphertext, and binds the ciphertext to its grant id:

```rust [src/auth_stores.rs]
pub struct DbGrantStore {
    pool: PgPool,
    key: RandomizedNonceKey,
}

impl DbGrantStore {
    /// `key` is 32 bytes from your secret manager.
    pub fn new(pool: PgPool, key: &[u8; 32]) -> Result<Self> {
        let key = RandomizedNonceKey::new(&AES_256_GCM, key).map_err(|_| {
            ErrorCode::Cfg001
                .error()
                .with_message("Invalid grant encryption key")
        })?;
        Ok(Self { pool, key })
    }

    // The ciphertext is bound to its grant id: a row copied to another grant does not decrypt.
    fn encrypt(&self, grant_id: &str, refresh_token: &SecretString) -> Result<Vec<u8>> {
        let mut sealed = refresh_token.expose_secret().as_bytes().to_vec();
        let nonce = self
            .key
            .seal_in_place_append_tag(Aad::from(grant_id.as_bytes()), &mut sealed)
            .map_err(|_| store_error(std::io::Error::other("encryption failed")))?;
        Ok([nonce.as_ref(), sealed.as_slice()].concat())
    }

    fn decrypt(&self, grant_id: &str, stored: &[u8]) -> Result<SecretString> {
        let failed = || store_error(std::io::Error::other("decryption failed"));
        let (nonce, sealed) = stored.split_at_checked(NONCE_LEN).ok_or_else(failed)?;
        let nonce = Nonce::try_assume_unique_for_key(nonce).map_err(|_| failed())?;
        let mut opened = sealed.to_vec();
        let plain = self
            .key
            .open_in_place(nonce, Aad::from(grant_id.as_bytes()), &mut opened)
            .map_err(|_| failed())?;
        String::from_utf8(plain.to_vec())
            .map(SecretString::new)
            .map_err(|_| failed())
    }
}

#[async_trait]
impl GrantStore for DbGrantStore {
    async fn get(&self, grant_id: &str) -> Result<Option<SecretString>> {
        let stored: Option<Vec<u8>> =
            sqlx::query_scalar("SELECT refresh_token FROM auth_grants WHERE grant_id = $1")
                .bind(grant_id)
                .fetch_optional(&self.pool)
                .await
                .map_err(store_error)?;
        stored
            .map(|bytes| self.decrypt(grant_id, &bytes))
            .transpose()
    }

    async fn set(&self, grant_id: &str, refresh_token: &SecretString) -> Result<()> {
        sqlx::query(
            "INSERT INTO auth_grants (grant_id, refresh_token) VALUES ($1, $2) \
             ON CONFLICT (grant_id) DO UPDATE SET refresh_token = EXCLUDED.refresh_token",
        )
        .bind(grant_id)
        .bind(self.encrypt(grant_id, refresh_token)?)
        .execute(&self.pool)
        .await
        .map_err(store_error)?;
        Ok(())
    }

    async fn delete(&self, grant_id: &str) -> Result<()> {
        sqlx::query("DELETE FROM auth_grants WHERE grant_id = $1")
            .bind(grant_id)
            .execute(&self.pool)
            .await
            .map_err(store_error)?;
        Ok(())
    }
}
```

## Locks and replay store

`GrantLock` across replicas, with a PostgreSQL advisory lock held for as long as the guard lives, and a `ReplayStore` on Redis:

```rust [src/auth_stores.rs]
/// One refresh at a time per grant, across replicas. Each holder keeps one connection.
pub struct PgGrantLock {
    pool: PgPool,
}

impl PgGrantLock {
    pub const fn new(pool: PgPool) -> Self {
        Self { pool }
    }
}

#[async_trait]
impl GrantLock for PgGrantLock {
    async fn hold(&self, grant_id: &str) -> Result<LockGuard> {
        let mut tx = self.pool.begin().await.map_err(store_error)?;
        sqlx::query("SELECT pg_advisory_xact_lock(hashtext($1))")
            .bind(grant_id)
            .execute(&mut *tx)
            .await
            .map_err(store_error)?;
        // Dropping the guard rolls the transaction back, which releases the lock.
        Ok(LockGuard::new(tx))
    }
}

pub struct RedisReplayStore {
    redis: ConnectionManager,
}

impl RedisReplayStore {
    pub const fn new(redis: ConnectionManager) -> Self {
        Self { redis }
    }
}

#[async_trait]
impl ReplayStore for RedisReplayStore {
    async fn claim(&self, jti: &str, expires_at: f64) -> Result<bool> {
        let now = SystemTime::now()
            .duration_since(UNIX_EPOCH)
            .map_or(0.0, |elapsed| elapsed.as_secs_f64());
        let ttl_ms = ((expires_at - now) * 1000.0).ceil().max(1.0) as u64;
        let mut redis = self.redis.clone();
        // SET ... NX only succeeds for the first caller.
        let stored: Option<String> = redis::cmd("SET")
            .arg(format!("logout-jti:{jti}"))
            .arg("1")
            .arg("NX")
            .arg("PX")
            .arg(ttl_ms)
            .query_async(&mut redis)
            .await
            .map_err(store_error)?;
        Ok(stored.is_some())
    }
}
```

Each holder of the PostgreSQL lock keeps one pooled connection while the grant is refreshed, and the grant store needs another: size the pool for the number of refreshes that can run at once.

Wire them together:

```rust [src/main.rs]
use std::sync::Arc;

use auth_ai::web::{AuthHandlers, SessionStore};
use auth_ai::{AuthAiError, AuthClient, GrantManager};
use redis::aio::ConnectionManager;
use sqlx::PgPool;

mod auth_stores;

use auth_stores::{DbGrantStore, DbSessionStore, PgGrantLock, RedisReplayStore};

fn build_handlers(
    auth: AuthClient,
    pool: PgPool,
    redis: ConnectionManager,
    encryption_key: &[u8; 32],
    cookie_secret: String,
) -> Result<AuthHandlers, AuthAiError> {
    let grants = GrantManager::builder(
        auth.clone(),
        DbGrantStore::new(pool.clone(), encryption_key)?,
    )
    .lock(PgGrantLock::new(pool.clone()))
    .build();
    let sessions: Arc<dyn SessionStore> = Arc::new(DbSessionStore::new(pool));
    AuthHandlers::builder(auth, grants, sessions, cookie_secret)
        .replay_store(Arc::new(RedisReplayStore::new(redis)))
        .build()
}
```

::callout{icon="i-lucide-info" color="info"}
The access-token cache of `GrantManager` stays in each process: that is by design, since access tokens are never persisted. Each replica mints its own, serialised by the shared lock.
