The SDK reads **no environment variable**: every value is passed in code. Validation happens when the object is built, and an invalid configuration returns `CFG_001` (see [Error codes](/docs/reference/error-codes)) naming every offending field in the message. Options are set through builders: the mandatory members are arguments of the constructor function, the others are methods, and `build()` validates.

## `AuthClientConfig`

```rust
impl AuthClientConfig {
    pub fn builder(
        issuer: impl Into<String>,
        client_id: impl Into<String>,
        redirect_uri: impl Into<String>,
    ) -> AuthClientConfigBuilder;
}

impl AuthClientConfigBuilder {
    pub fn build(self) -> Result<AuthClientConfig, AuthAiError>; // CFG_001
}
```

`AuthClientConfig` is immutable once built; the resolved values are read through accessors (`issuer()`, `client_id()`, `client_secret()`, `token_endpoint_auth_method()`, `redirect_uri()`, `post_logout_redirect_uri()`, `scopes()`, `resources()`, `gateway_url()`, `resource_sharing()`, `clock_tolerance_seconds()`, `timeout()`). `build()` collects **every** invalid option before it fails, so one error lists them all.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `issuer` | `impl Into<String>` | required | auth-service URL. An absolute **HTTPS** URL (no loopback exception) with no credentials, query or fragment. It is compared verbatim to the `iss` claim and to the `issuer` of the discovery document, so write it exactly as auth-service advertises it, without a trailing slash. |
| `client_id` | `impl Into<String>` | required | The application's OAuth client id (its slug). Non-empty. |
| `redirect_uri` | `impl Into<String>` | required | The callback URL registered in auth-service. HTTPS, or HTTP for `localhost`, `127.0.0.1` and `[::1]` only. |
| `.client_secret(secret)` | `impl Into<SecretString>` | none | Absent for a public client, which then relies on PKCE alone. Needed by `client_credentials` and the [machine API](/docs/reference/server-api#machineapi). A `&str` or a `String` is converted; non-empty. |
| `.token_endpoint_auth_method(method)` | `TokenEndpointAuthMethod` | `ClientSecretBasic` | How the secret is sent to the token endpoint: `ClientSecretBasic` or `ClientSecretPost`. Ignored without a client secret. |
| `.post_logout_redirect_uri(uri)` | `impl Into<String>` | none | Sent as `post_logout_redirect_uri` by `AuthClient::logout_url`. Same URL rules as `redirect_uri`. |
| `.scopes(scopes)` | `IntoIterator<Item: Into<String>>` | `DEFAULT_SCOPES` | Replaces the requested scopes. Must include `openid`; each scope is non-empty. Duplicates are dropped. |
| `.resources(resources)` | `IntoIterator<Item: Into<String>>` | empty | RFC 8707 audiences requested at sign-in, each an absolute URL. Every refresh can narrow to one. |
| `.gateway_url(url)` | `impl Into<String>` | none | Public URL of the LiteLLM gateway. HTTPS (or loopback HTTP), **no trailing slash**: it is compared verbatim to `aud`. Turns on the gateway and wallet audiences. |
| `.resource_sharing(enabled)` | `bool` | `false` | Ask at sign-in for the `resources:self:manage` scope and the auth-service audience, needed by `ai.for_user(id)?.resources`. |
| `.clock_tolerance_seconds(seconds)` | `u64` | `5` | Allowed clock skew when verifying tokens. From `0` to `300`. |
| `.timeout(timeout)` | `Duration` | `10 s` | Timeout of every request: discovery, keys, token endpoint, API and gateway. Greater than zero. |

`DEFAULT_SCOPES` is `["openid", "profile", "email", "roles", "permissions", "features", "offline_access"]`. `WALLET_SELF_SCOPE` is `"wallet:self:read"` and `RESOURCE_SELF_SCOPE` is `"resources:self:manage"`.

With `gateway_url`, `build()` adds `WALLET_SELF_SCOPE` to `scopes`, and the gateway URL and the `issuer` to `resources`, without duplicates. With `resource_sharing(true)`, it adds `RESOURCE_SELF_SCOPE` to `scopes` and the `issuer` to `resources`, also without duplicates. The added values come after the ones you listed.

```rust
use std::time::Duration;

use auth_ai::{AuthAiError, AuthClient, AuthClientConfig, TokenEndpointAuthMethod};

fn build_client() -> Result<AuthClient, AuthAiError> {
    let config = AuthClientConfig::builder(
        "https://auth.example.com",
        "my-app",
        "https://app.example.com/auth/callback",
    )
    .client_secret("<client-secret>")
    .token_endpoint_auth_method(TokenEndpointAuthMethod::ClientSecretBasic)
    .post_logout_redirect_uri("https://app.example.com/auth/logout/callback")
    .gateway_url("https://llm.example.com")
    .resources(["https://app.example.com"])
    .timeout(Duration::from_secs(15))
    .build()?;

    // The app, the gateway, then the issuer.
    assert_eq!(
        config.resources(),
        [
            "https://app.example.com",
            "https://llm.example.com",
            "https://auth.example.com"
        ]
    );
    // The wallet scope comes last.
    assert_eq!(config.scopes().last().map(String::as_str), Some("wallet:self:read"));

    AuthClient::new(config)
}
```

`SecretString` wraps a credential: its `Debug` output is `SecretString([REDACTED])` and its memory is zeroed on drop. Read it back with `expose_secret()` at the point of use only. The same holds for every token the SDK returns (`TokenSet`, `LoginHandshake`, `Session::id_token`, `AccessToken`).

## `AuthClient`

| Constructor | Description |
| --- | --- |
| `AuthClient::new(config) -> Result<AuthClient, AuthAiError>` | Builds the client on the default `reqwest` transport. `CFG_001` when the TLS backend cannot be initialised. |
| `AuthClient::with_transport(config, transport: Arc<dyn Transport>) -> AuthClient` | Builds the client on a transport of your own. |

`AuthClient` is cheap to clone: clones share one transport, the discovery cache and the key cache. There is nothing to close. `auth.config()` returns the resolved configuration and `auth.transport()` the shared transport.

Discovery and the signing keys are cached for an hour; a failed discovery is not cached, so the next call retries. JWTs are accepted for the algorithms `ES256`, `ES384`, `ES512`, `RS256`, `RS384`, `RS512`, `PS256`, `PS384`, `PS512` and `Ed25519`, pinned to the one the provider advertises for ID tokens; a provider that advertises none of them fails discovery with `OIDC_001`.

## `AuthHandlers`

`AuthHandlers::builder(auth, grants, sessions, secret)` takes the four mandatory members; `build()` is synchronous. Details of the routes are in [Web handlers and axum](/docs/reference/web-and-axum).

```rust
impl AuthHandlers {
    pub fn builder(
        auth: AuthClient,
        grants: GrantManager,
        sessions: Arc<dyn SessionStore>,
        secret: impl Into<SecretString>,
    ) -> AuthHandlersBuilder;
}

impl AuthHandlersBuilder {
    pub fn build(self) -> Result<AuthHandlers, AuthAiError>; // CFG_001
}
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `auth` | `AuthClient` | required | The OIDC client. |
| `grants` | `GrantManager` | required | Stores the refresh token obtained at sign-in. |
| `sessions` | `Arc<dyn SessionStore>` | required | Where sessions live. Use a database in production. |
| `secret` | `impl Into<SecretString>` | required | At least 32 characters, random. Seals the sign-in and sign-out cookies. Keep it out of source control. |
| `.base_path(path)` | `impl Into<String>` | `"/auth"` | Prefix of the routes. Must start with `/`, not end with `/`, and use only letters, digits, `/`, `_` and `-`. The path of `redirect_uri` must be `<base_path>/callback`. |
| `.default_redirect(path)` | `impl Into<String>` | `"/"` | Where users land after sign-in or sign-out without a target. |
| `.session_ttl_seconds(seconds)` | `i64` | `28800` (8 h) | Absolute lifetime of a session. Capped at the ID token's `exp` when no refresh token was issued. |
| `.claims_renew_seconds(seconds)` | `i64` | `900` | How often claims are renewed from the provider. |
| `.require_provider_session(require)` | `bool` | `true` | Refuse an ID token without `sid`: no back-channel logout could ever reach such a session. |
| `.allow_missing_logout_token_typ(allow)` | `bool` | `false` | Accept a back-channel logout token without a `typ` header. Only for a known non-conforming provider. |
| `.error_redirect(path)` | `impl Into<String>` | none | Redirect target of a failed sign-in, with `?error=<code>`. A JSON `403` when unset. |
| `.ai(ai)` | `AiClient` | none | Adds the `/wallet`, `/wallet/stats` and `/models` routes. |
| `.replay_store(store)` | `Arc<dyn ReplayStore>` | `MemoryReplayStore` | Remembers accepted logout tokens. Share it across replicas. |
| `.on_sessions_ended(callback)` | `SessionsEndedCallback` | none | Called after sessions end (sign-out or back-channel logout). |
| `.on_error(callback)` | `ErrorCallback` | none | Receives unexpected failures and the ones the response must not detail. |

`build()` returns `CFG_001` when `base_path` is malformed, when the path of `redirect_uri` is not `<base_path>/callback`, or when the secret is shorter than 32 characters. The cookies carry the `__Host-` prefix and the `Secure` flag when `redirect_uri` is HTTPS.

The callbacks are reference-counted closures:

| Alias | Definition |
| --- | --- |
| `ErrorCallback` | `Arc<dyn Fn(&AuthAiError) + Send + Sync>` |
| `SessionsEndedCallback` | `Arc<dyn Fn(Vec<Session>) -> BoxFuture<'static, Result<(), AuthAiError>> + Send + Sync>` |
| `LogoutCallback` | `Arc<dyn Fn(BackchannelLogoutEvent) -> BoxFuture<'static, Result<(), AuthAiError>> + Send + Sync>` |

`BoxFuture<'a, T>` is `Pin<Box<dyn Future<Output = T> + Send + 'a>>`.

```rust
use std::sync::Arc;

use auth_ai::web::{AuthHandlers, MemorySessionStore, SessionStore};
use auth_ai::{AuthAiError, AuthClient, ErrorCallback, GrantManager, MemoryGrantStore};

fn build_handlers(auth: AuthClient, cookie_secret: String) -> Result<AuthHandlers, AuthAiError> {
    let grants = GrantManager::new(auth.clone(), MemoryGrantStore::new());
    let sessions: Arc<dyn SessionStore> = Arc::new(MemorySessionStore::new());
    let on_error: ErrorCallback = Arc::new(|err| {
        eprintln!("auth-ai: {}", err.to_json());
    });
    AuthHandlers::builder(auth, grants, sessions, cookie_secret)
        .base_path("/auth")
        .default_redirect("/app")
        .session_ttl_seconds(4 * 3600)
        .claims_renew_seconds(300)
        .error_redirect("/sign-in-failed")
        .on_error(on_error)
        .build()
}
```

## Other constructors

| Constructor | Options | Notes |
| --- | --- | --- |
| `GrantManager::new(auth, store)` | `auth: impl GrantAuth` (an `AuthClient`), `store: impl GrantStore`. | The default in-process lock and a 30-second expiry skew. |
| `GrantManager::builder(auth, store)` | `.lock(impl GrantLock)`, `.expiry_skew_seconds(i64)`, then `.build()`. | `DEFAULT_EXPIRY_SKEW_SECONDS` is `30`. See [Sessions and grants](/docs/concepts/sessions-and-grants). |
| `AiClient::new(auth, grants)` | `auth: AuthClient`, `grants: GrantManager`. | `for_user(grant_id)` returns a `UserAi` with `wallet`, `resources` and `gateway()`. |
| `MachineApi::new(&auth)` | `auth: &AuthClient`. | `CFG_001` without a client secret. |
| `BearerVerifier::new(auth, audience)` | `audience` must be an absolute URL. | `CFG_001` otherwise. |
| `BackchannelLogoutHandler::new(auth, on_logout)` | `.replay_store(Arc<dyn ReplayStore>)`, `.allow_missing_typ(bool)`, `.on_error(ErrorCallback)`. | For use without the sign-in handlers. The replay store defaults to `MemoryReplayStore`. |
| `WebRequest::new(method, url)` | `.with_header(name, value)`, `.with_body(bytes)`. | `url` is absolute. See [`WebRequest` and `WebResponse`](/docs/reference/web-and-axum#webrequest-and-webresponse). |

The wallet, resource-sharing and gateway clients have no public constructor: you get them from `ai.for_user(id)`, which wires the tokens for you (`UserAi::wallet`, `UserAi::resources` and `UserAi::gateway()`).

## Machine client environment

`MachineApi` calls the auth-service REST API as your application, with `client_credentials` tokens minted from its own secret:

- the `AuthClientConfig` needs a `client_secret`; `MachineApi::new` returns `CFG_001` without one. Read it from your own secret store or environment at startup, and fail if it is missing (an unset variable would otherwise build a public client);
- the machine API uses the **same transport and timeout** as the `AuthClient` it is built from;
- one token is cached **per scope** until 30 seconds before it expires, and concurrent calls for the same scope wait on one token request;
- a `401` from the API drops the cached token and retries the call once;
- the scopes it asks for are `billing:read`, `consumption:read`, `consumption:write`, `resources:validate`, `resources:authorize` and `resources:usage:write`. A scope that auth-service refuses surfaces as `TOK_004` with the scope in `details["scope"]`.

## `Transport`

Every HTTP request of the SDK goes through the `Transport` trait: discovery, the keys, the token endpoint, UserInfo, the REST API and the gateway. The default is `ReqwestTransport`: `reqwest` with rustls, HTTP/2 negotiated over TLS (HTTP/1.1 fallback), gzip and brotli responses, **no redirect followed**, and a body limit of `MAX_RESPONSE_BYTES` (16 MiB). Replace it to add a proxy, an observability layer or, in tests, an in-memory identity provider.

```rust
#[async_trait::async_trait]
pub trait Transport: Send + Sync + std::fmt::Debug {
    async fn send(&self, request: HttpRequest) -> Result<HttpResponse, TransportError>;
}
```

| Type | Description |
| --- | --- |
| `HttpRequest` | `method: Method` (`Get`, `Post`, `Put`, `Patch` or `Delete`), `url: String` (absolute), `headers: Vec<(String, String)>` (lowercase names), `body: Option<Vec<u8>>`, `timeout: Duration` (the upper bound of the whole exchange, taken from the configuration). Built with `HttpRequest::new(method, url, timeout)`, `.with_header(name, value)`, `.with_form(pairs)` and `.with_json(&value)`; read with `header(name)`. Its `Debug` output hides headers and body. |
| `HttpResponse` | `status: u16`, `headers: Vec<(String, String)>`, `body: Vec<u8>`. `is_success()`, `header(name)`, `parse_json::<T>()`, `json_value()` and `HttpResponse::json(status, &value)`. |
| `TransportError` | The exchange failed before a complete answer was read: connection, TLS, timeout or an oversized body. `TransportError::new(message)`; the message must not contain a credential. |
| `Method` | `Get`, `Post`, `Put`, `Patch` or `Delete`; `as_str()`. |

A transport **must not follow redirects** and must treat a non-2xx status as an answer, not as an error. It must honour `request.timeout`. A `TransportError` becomes `OIDC_001`, `OIDC_003`, `API_001`, `GW_004` or `TOK_001` depending on the call that failed.

`ReqwestTransport::new()` returns `CFG_001` when the TLS backend cannot be initialised. `default_transport()` returns it as an `Arc<dyn Transport>`.

```rust
use std::sync::Arc;

use async_trait::async_trait;
use auth_ai::{
    AuthClient, AuthClientConfig, HttpRequest, HttpResponse, ReqwestTransport, Transport,
    TransportError,
};

#[derive(Debug)]
struct Traced(ReqwestTransport);

#[async_trait]
impl Transport for Traced {
    async fn send(&self, request: HttpRequest) -> Result<HttpResponse, TransportError> {
        // Log the method only: the URL and the headers can carry identifiers and tokens.
        tracing::debug!(method = request.method.as_str(), "auth-ai request");
        self.0.send(request).await
    }
}

fn traced_client(config: AuthClientConfig) -> Result<AuthClient, auth_ai::AuthAiError> {
    let transport = Arc::new(Traced(ReqwestTransport::new()?));
    Ok(AuthClient::with_transport(config, transport))
}
```

Your crate needs `async-trait` to implement the trait.
