## Where the SDK stands

`auth-ai` `0.1.0` is the first release of the Rust port of the TypeScript SDK [`@circle-rd/auth-ai`](https://docs.circle-cyber.com/auth-ai/typescript/) and of the [Python SDK](https://docs.circle-cyber.com/auth-ai/python/). The port reproduces their behaviours, wire contract and error codes, and is aligned with their `0.4.0`. The public API is not stable: while the major version is `0`, a breaking change bumps the minor version, and the [changelog](https://github.com/circle-rd/auth-ai-rs/blob/main/CHANGELOG.md) lists it with a migration note.

The surface that exists today is described in the [Reference](/docs/reference/configuration): the async OIDC relying party, the backend-for-frontend handlers, the axum adapter, bearer token verification, back-channel logout, the wallet and gateway clients, and the machine API for billing, consumption and resource sharing. The resource-sharing calls need an auth-service with `RESOURCE_SHARING_ENABLED`.

## Not available yet

| Gap | What to do today |
| --- | --- |
| **Only an axum adapter** | The framework-agnostic `WebRequest` and `WebResponse` handlers mount in any framework through a small bridge. The [other frameworks](/docs/guides/backend/other-frameworks) guide shows how. Adapters for actix-web and Rocket may follow as needs appear. |
| **No `Ed448` signatures** | The SDK verifies ES256, ES384, ES512, RS256, RS384, RS512, PS256, PS384, PS512 and the fully specified `Ed25519`. A provider that only advertises `Ed448` fails discovery with `OIDC_001`: no maintained Rust implementation exists yet. `EdDSA` is refused by design, because RFC 9864 deprecates that name. |
| **No blocking facade** | The SDK is async only, on Tokio. A synchronous application has to host a Tokio runtime to use it. |
| **No frontend code** | The browser client and the React and Vue bindings are in the TypeScript package. See [Use the TypeScript client](/docs/guides/frontend/use-the-typescript-client). |
| **No database-backed stores** | `SessionStore`, `GrantStore`, `GrantLock` and `ReplayStore` are traits with in-memory implementations. [Implement the stores](/docs/guides/backend/custom-stores) shows how to back them with your database. |

## Staying aligned with the other SDKs

The wire contract (the BFF routes, the cookie formats and the error codes) is shared with the TypeScript and Python SDKs: a change to it is made in all three or in none. A feature of another SDK may therefore reach the Rust port after it ships there.

## Not planned here

The SDK has no debit API, by design: the LiteLLM gateway debits the wallet after each call. See [Credit wallet and LiteLLM gateway](/docs/concepts/wallet-and-gateway).

To suggest or discuss a feature, open an issue on [GitHub](https://github.com/circle-rd/auth-ai-rs/issues).
